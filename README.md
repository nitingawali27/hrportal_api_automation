# API Automation with Pytest

This project contains automated tests for the APIs documented at [Aligned Automation API Docs](http://training.alignedautomation.com:8009/docs#).

---

## Prerequisites
- Python 3.8 or above
- pip
- Virtual environment (recommended)

---

## Installation
```bash
git clone <repository-url>
cd <repository-directory>
python -m venv venv
venv\Scripts\activate   # Windows
source venv/bin/activate # Linux/Mac
pip install -r requirements.txt
